First release of the ESP32 LED Sign firmware — the exact build running on the 10-board sign. The phone UI shows it as **fw 0.4.0 · c884749 · build ce1fbe40**.

One firmware for every board: the hub serves the phone page over its own Wi-Fi and drives the other boards over ESP-NOW. There are no cables between boards.

## What's in it
- Phone control with a captive portal (no app), on iPhone and Android, several phones at once.
- Messages up to 60 characters with symbols ♥ ★ ✓ ✗ → ← ↑ ↓ ◆ ● ☺ ☹, automatic word grouping with live preview, and word changes synchronised across boards (≈ 8 ms skew).
- Colours, Blink / Fade / Cycle, **Rainbow Bands** and **Rainbow Flow** (Down, Up, Right, Left, Diagonal across the whole sign).
- Plug-and-play numbering by power-on order, remembered across restarts. Each board can be identified or flipped, and its status is shown live.
- Over-the-air updates from the phone: the hub updates every board in turn (~20 s per board) and rolls back automatically if a new image fails.

Feature tour: [FEATURES.md](https://github.com/Alternating/esp32-LED-sign/blob/v0.4.0/docs/FEATURES.md) · Video: [Esp32 - led signs - esp-now](https://www.youtube.com/watch?v=DiyBTvzq21I)

## Downloads
| File | Use |
|---|---|
| `LED_Sign_HUB_install.bin` | first USB install of the **one** hub board (offset `0x0`) |
| `LED_Sign_NODE_install.bin` | first USB install of **every other** board (offset `0x0`) |
| `LED_Sign_ota.bin` | every update after that — upload from the phone |
| `SHA256SUMS`, `INSTALL.txt` | checksums and short install notes |
| `LED_Sign_firmware_v0.4.0.zip` | all of the above in one file |

## First install (USB, once per board)
1. Hub board: `esptool --chip esp32 --port <port> --baud 115200 write-flash -z 0x0 LED_Sign_HUB_install.bin`
2. Every other board: the same command with `LED_Sign_NODE_install.bin`. You can also use `python tools/flasher.py` from the repo, which guides you through the hub first and then each extra board.
3. Keep the board plugged in until esptool prints **"Hash of data verified"**.
4. Power the hub, then the other boards one at a time in sign order. Join `LEDSIGN-HUB` (password `sign1234`) on a phone and the control page opens.

A USB install erases that board's saved settings. Boards running a build from before the over-the-air partition layout also need this USB install once.

## Updating later
Phone on the sign's Wi-Fi → **Settings → Firmware** → choose `LED_Sign_ota.bin` → **Upload to hub**. When the hub is back, tap **Update all boards**. Role, positions and message are kept.

## Build
Arduino-ESP32 core 3.3.12 (IDF 5.5.5) · FastLED 3.10.9 · ArduinoJson 7.4.3 · FQBN `esp32:esp32:lolin32:PartitionScheme=min_spiffs` · app 1,140,743 B (58 % of a 1.9 MB slot). Built from `c884749`. Commits after that up to this tag change documentation only, so the firmware sources are identical.

Verified on 10 real boards: the image was uploaded to the hub from a phone, and the hub updated all 9 other boards over the air.

## Known minor issues
- If a board falls back to its old image during an update, the hub only marks that board failed after a 120 s timeout, not straight away.
- While a firmware file is uploading to the hub (~13 s), the hub's own word changes can lag by up to ~0.2 s.
